## 个人出版

这是用于验证发布流程的合成内容。站内搜索应能找到“个人出版”，并返回中文页面。

> [!NOTE]
> 提示块需要在 Markdown 中正常显示。

| 步骤 | 验收                       |
| ---- | -------------------------- |
| 构建 | 生成静态页面和当次搜索索引 |
| 验证 | 检查语言、链接和文章结构   |

## 维护

同一篇文章移动到不同文件夹后，仍使用原来的公开地址。
